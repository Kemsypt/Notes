How to Use the Bingo Sheet Generator

  • Bingo Options: Type each Bingo entry on its own line.
  • Grid Size: Set rows and columns for the sheet.
  • Number of Sheets: Choose how many unique Bingo sheets to create.
  • Sheet Title/Recipient: Enter a title. Click Recipient to add names, one per line.
  • Download Type: Single PDF, individual PDFs, or a ZIP file.
  • View PDFs: After generation, use the View buttons to preview PDFs in this page without downloading.
  • Colour: Click the title to open the colour picker or use rainbow mode.
